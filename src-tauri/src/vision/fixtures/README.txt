hello-world.rgb is a synthetic 320 x 80, 8-bit RGB image, top-down,
with no header or row padding. It contains HELLO WORLD in black
Helvetica 32px on white, drawn with AppKit at x=20, y=24 (bottom-up).
It is test data created for Gullbert, not a screen capture. MIT licensed
like the application. It exercises the embedded Windows OCR models
without depending on installed fonts or a live desktop during tests.
